# Landing Page Pricing

Ce projet est une landing page qui affiche les informations d'abonnement avec trois plans : **Free**, **Premium** et **Entreprise**.

## Technologies utilisées

- **[Next.js](https://nextjs.org)** : Framework frontend.
- **[Tailwind CSS](https://tailwindcss.com)** : Framework CSS.
- **[Shadcn UI](https://ui.shadcn.com)** : Bibliothèque de composants.
- **TypeScript** : Typage statique pour les variables.

## Structure du projet

- Les composants spécifiques aux fonctionnalités ui sont situés dans le dossier [`components/design`](components/design).
- Les composants réutilisables sont situés dans le dossier [`components/ui`](components/ui).

## Getting Started

Pour démarrer le serveur de développement :

Cloner le projet :

git clone https://github.com/HugoCoder1/saas-template-figma.git
ensuite
cd saas-template-figma
Installer les dépendances :
npm install
ou
yarn install
ou
pnpm install
ou
bun install
Lancer le serveur de développement :

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```
